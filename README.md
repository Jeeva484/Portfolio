## 🚀 In-Depth Project Case Studies

### 1. SynapseAI — Enterprise RAG AI Assistant
* **Role:** Lead Full-Stack & AI Engineer | **Timeline:** Jan 2025 – Apr 2025
* **Tech Stack:** Next.js, React, TypeScript, FastAPI, Python, PostgreSQL, OpenAI GPT, LangChain, Qdrant, Docker, Vercel

```
[User Document: PDF/DOCX] ──> [Semantic Text Chunker (500 tokens)] 
                                         │
                                         ▼
                            [OpenAI Embedding Model]
                                         │
                                         ▼
                         [Qdrant Vector DB (HNSW Index)]
                                         │
[User Query] ───────────────> [FastAPI Retrieval Gateway]
                                         │
                                         ▼
                          [LangChain Prompt Context] ──> [OpenAI GPT-4o] ──> [Grounded Response with Citations]
```

* **Problem Statement:** Traditional LLMs suffer from severe factual hallucination and lack real-time access to proprietary enterprise documentation.
* **Engineering Architecture:**
  * Implemented an end-to-end Retrieval-Augmented Generation (RAG) system with a **FastAPI** backend and **Next.js/TypeScript** frontend.
  * Ingested unstructured documents, segmented content into semantically coherent chunks with overlap, and indexed 1536-dimensional embeddings into **Qdrant Vector Database**.
  * Enforced a strict cosine similarity cutoff threshold (0.78) and citation provenance to achieve **100% citation grounding** with sub-250ms vector query retrieval.
  * Multi-tenant metadata filtering implemented in **PostgreSQL** to ensure authorized document isolation across distinct user sessions.
  * Packaged backend services into **Docker** containers for standardized continuous deployment.

### 2. Hemorrhagic Stroke Prediction Using Deep Learning Algorithm
* **Role:** Researcher & Deep Learning Engineer | **Timeline:** Jun 2024 – Nov 2024
* **Tech Stack:** Python, TensorFlow, Keras, CNN, OpenCV, Flask, Render
* **Publication:** **IEEE International Conference on Green Computing for Communication Technologies (ICGCCT 2026)** (Presented & Published: March 2026)

* **Problem Statement:** Intracranial hemorrhage requires immediate clinical detection. Manual CT scan interpretation can cause diagnostic latency during acute emergency department admissions.
* **Engineering & Research Methodology:**
  * Developed a deep Convolutional Neural Network (CNN) trained on cranial axial non-contrast computed tomography (CT) slices.
  * Implemented automated **OpenCV** image preprocessing: Contrast-Limited Adaptive Histogram Equalization (CLAHE) for artifact suppression and automated skull stripping to isolate brain parenchyma.
  * Deployed model inference through a lightweight **Flask** REST API hosted on Render, returning diagnostic probability, bounding coordinates, and classification within 140ms.
  * Validated through extensive cross-validation, achieving clinical-grade sensitivity and specificity.
